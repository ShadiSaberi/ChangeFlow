# مدل دادهٔ ChangeFlow

## جدول `change_requests`

| فیلد           | نوع      | کاربرد                                                                     |
| -------------- | -------- | -------------------------------------------------------------------------- |
| `id`           | عدد صحیح | شناسهٔ یکتای درخواست                                                       |
| `title`        | متن      | عنوان درخواست                                                              |
| `description`  | متن      | شرح تغییر پیشنهادی                                                         |
| `reason`       | متن      | دلیل درخواست تغییر                                                         |
| `requester_id` | عدد صحیح | شناسهٔ ثبت‌کننده از جدول `users`                                           |
| `status`       | متن      | یکی از `Draft`، `PendingReview`، `ChangesRequested` یا `Approved`          |
| `version`      | عدد صحیح | از ۱ شروع می‌شود و با هر ویرایش یا تغییر وضعیت موفق یک واحد افزایش می‌یابد |

در زمان ثبت، سرور `requester_id` را از کاربر احراز هویت‌شده می‌گیرد و وضعیت اولیه را `Draft` قرار می‌دهد. شناسهٔ درخواست و شناسهٔ ثبت‌کننده پس از ایجاد ثابت می‌مانند.

## جدول `users`

| فیلد   | نوع      | کاربرد             |
| ------ | -------- | ------------------ |
| `id`   | عدد صحیح | شناسهٔ یکتای کاربر |
| `name` | متن      | نام کاربر آزمایشی  |

## جدول `user_roles`

| فیلد      | نوع      | کاربرد                           |
| --------- | -------- | -------------------------------- |
| `user_id` | عدد صحیح | شناسهٔ کاربر از جدول `users`     |
| `role`    | متن      | یکی از `Requester` یا `Reviewer` |

ترکیب `user_id` و `role` یکتاست. یک کاربر می‌تواند هر دو نقش را داشته باشد. برای شبیه‌سازی لغو مجوز، نقش مربوط از همین جدول حذف می‌شود.

## جدول `access_tokens`

| فیلد         | نوع      | کاربرد                                |
| ------------ | -------- | ------------------------------------- |
| `token_hash` | متن      | اثر انگشت یکتای توکن آزمایشی          |
| `user_id`    | عدد صحیح | شناسهٔ کاربری که توکن به او تعلق دارد |
